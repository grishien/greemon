# Roadmap: greemon (порт hwmon на PowerShell)

## Цель

Переписать Python-утилиту `hwmon` (терминальный монитор железа в стиле Overview из Strata) на PowerShell так, чтобы:

- после установки утилита запускалась командой **`greemon`** из любой текущей папки в терминале (cmd, Windows PowerShell 5.1): без пути к файлу и без перехода в папку проекта, потому что папка с шимом добавлена в `PATH`;
- не нужны ни Python, ни модули из PSGallery, ни права администратора;
- экран выглядел как у референса: шапка, вкладки, полоса Model state, 8 плиток со спарклайнами (Speed, GPU load, VRAM, GPU temp, Power, PCIe, CPU, Disk read), полосы Context fill / Experts in VRAM / System RAM, таблица Recent requests, строка клавиш.

## Референс

Папка `\hwmon` внутри проекта (это распакованный `hwmon.zip`). Только читать: **не изменять, не копировать в итоговую поставку.** Код оттуда MIT (Strata); если переносишь код или константы, оставь ссылку на лицензию в README.

Что откуда брать (читай файлы, не полагайся на память):

| Что нужно | Файл |
|---|---|
| Раскладка, тексты плиток, цвета, спарклайны, полосы, таблица запросов | `hwmon\strata_cli\overview.py` (`build()` и `render()`) |
| Панель вкладок | `hwmon\strata_cli\nav.py` |
| Клавиши, интервал, метки LIVE / STALE / FROZEN, выбор глифов, минимальный размер окна | `hwmon\strata_cli\monitor.py` |
| Сбор данных: NVML, CPU, RAM, диск, история 60 точек | `hwmon\serve\telemetry.py` |
| Определение старой консоли Windows | `hwmon\strata_cli\consoleinfo.py` |
| Поведение автономной обвязки и флаги | `hwmon\hwmon.py`, `hwmon\README.md` |

## Правила работы для агента

- Идти строго по фазам. После каждого выполненного подпункта ставить `[x]` в этом файле.
- Имя команды: **`greemon`** (скрипт `greemon.ps1`, шим `greemon.cmd`). Референс-утилита называется `hwmon`, её имя в новом коде не использовать.
- Одна фаза = один коммит (или один блок правок), сообщение коммита начинается с номера фазы.
- Имена функций NVML, структуры и единицы измерения брать **из `hwmon\serve\telemetry.py`** (класс `_Nvml`, функции чтения CPU/RAM). Не придумывать имена по памяти: если чего-то нет в референсе, проверить в документации NVML и записать в `NOTES.md`.
- Код должен работать в **Windows PowerShell 5.1** (единственная целевая оболочка). Следствия: нет `` `e `` (использовать `[char]27`), нет `$PSStyle`, нет тернарного оператора и `?.`; код в `Add-Type` только на C# 5 (без интерполяции строк `$"..."`, без `?.`).
- Никаких внешних зависимостей и сетевых загрузок при установке.
- Если подпункт нельзя выполнить или результат расходится с референсом, остановиться, записать причину в `NOTES.md` и сообщить, а не обходить молча.

```
  tests\                 скрипты проверок
  README.md

```

### [x] Фаза 2. Сбор данных о железе

- [x] 2.1 Через `Add-Type` объявить P/Invoke к `nvml.dll`, используя функции и структуры из `_Nvml` в `hwmon\serve\telemetry.py`. Защита от повторного объявления типа (`if (-not ('...' -as [type]))`). Пути поиска DLL взять из референса; если там нет Windows-пути, проверить, где драйвер кладёт `nvml.dll`, и записать в `NOTES.md`.
- [x] 2.2 Чтение по индексу `-Gpu`: загрузка, VRAM used/total, температура, мощность и лимит мощности, поколение и ширина PCIe (текущие и максимальные), входящий PCIe-трафик, имя карты. Единицы привести к тем, что ждёт `overview.build()`: проверить по референсу (VRAM в байтах, мощность в ваттах и т. д.).
- [x] 2.3 Запасной путь без `nvml.dll`: один вызов `nvidia-smi --query-gpu=...` за такт с разбором CSV. Если нет ни NVML, ни `nvidia-smi`, плитки GPU показывают `--`, программа не падает.
- [x] 2.4 CPU %: `GetSystemTimes` через P/Invoke (как `_CpuRamFallback` в референсе) или `System.Diagnostics.PerformanceCounter`. Не использовать `Get-Counter` и `Get-CimInstance` внутри цикла: они тяжёлые.
- [x] 2.5 RAM used/total через `GlobalMemoryStatusEx` (как в референсе).
- [x] 2.6 Диск read/write МБ/с: счётчик PhysicalDisk `_Total` (Disk Read Bytes/sec, Disk Write Bytes/sec) или дельта счётчиков. Сверить смысл с `_disk()` в референсе.
- [x] 2.7 Статика, один раз при старте: число ядер (через CIM `Win32_Processor`, один запрос), число логических потоков, имя GPU, число GPU, VRAM total.
- [x] 2.8 Сэмплер раз в `-Interval` секунд, история по 60 значений на серию (константа `HISTORY` в референсе), недоступное значение хранится как `$null`, а не как 0.
- [x] 2.9 Режим `-Mock`: детерминированные синтетические данные для проверки отрисовки без GPU.

### [x] Фаза 4. Цикл и управление

- [x] 4.1 Альтернативный экран `ESC[?1049h` при старте, скрытый курсор `ESC[?25l`; в `finally` вернуть всё обратно (курсор, основной экран, кодировка) при любом выходе, включая ошибку и Ctrl+C.

## Критерии готовности

- [ ] В новом терминале любого из трёх видов команда `greemon` из любой текущей папки показывает Overview без Python и без полного пути.
- [ ] `q` и Ctrl+C корректно восстанавливают терминал.
- [ ] Работает в Windows PowerShell 5.1.
- [ ] Данные GPU совпадают с `nvidia-smi`; без GPU программа не падает.
- [ ] Расход ресурсов измерен и записан в `NOTES.md`.
