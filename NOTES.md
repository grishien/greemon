# NOTES

Заметки о решениях и расхождениях с референсом `hwmon`.

## Решения

- **Целевая оболочка — только Windows PowerShell 5.1.** Решение владельца проекта (2026-11-14, при работе над фазой 1): поддержка PowerShell 7+/pwsh исключена из требований, roadmap обновлён. На машине разработки pwsh не установлен.
- 1.1: `install.ps1` и `uninstall.ps1` созданы как заглушки, реализация — фаза 5. `tests\` пока пуст (скрипты проверок — фаза 7).

## Фаза 1

- 1.2: набор параметров сверен с `hwmon\hwmon.py`: `--gpu` (int, по умолчанию 0), `--label` (по умолчанию `hardware monitor`), `--interval` (float, по умолчанию 1.0), `--theme` (по умолчанию `auto`), `--glyphs` (`auto|unicode|solid|ascii`, по умолчанию `auto`). Параметры `-Url`, `-ApiKey`, `-Once`, `-Mock`, `-Help` в референсе отсутствуют — добавлены по roadmap (нужны фазам 4–6). Расхождений по смыслу одноимённых параметров нет.

## Проверки фазы 1 (2026-11-14)

Все проверки пройдены (17/17 PASS; harness — временный скрипт в `%TEMP%\opencode\greemon_phase1_check.ps1`):

- 1.2: значения по умолчанию принимаются (exit 0); все параметры одновременно (`-Gpu 1 -Interval 0.5 -Label "тест" -Theme dark -Glyphs ascii -Url http://localhost/ -ApiKey k -Mock -Once`) связываются без ошибок (exit 0); недопустимые `-Theme bogus` / `-Glyphs bogus` отклоняются `ValidateSet` (exit 1).
